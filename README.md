# FluxBeacon

FluxBeacon enables real-time event-driven data processing, leveraging a distributed architecture for scalable, auto-scaling, and load-balanced server-to-gateway communication.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/FluxBeacon.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

FluxBeacon is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
